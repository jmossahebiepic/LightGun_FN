# First run

## Choose a path

**Original authorized collaborator:** open your existing local descriptor in
UEFN. Preserve that identity. Descriptors are now ignored by Git.

**New creator with permission to use the source:** create a blank project through
UEFN Project Browser. Do not reuse another account's project/module IDs. The
source ZIP contains no descriptor and is not itself a playable island.

## Prerequisites

- Windows, UEFN and Fortnite installed through supported launchers, with account
  access and the permissions described in RIGHTS.md.
- A release supporting the pointer/input APIs. Historical project compatibility
  was 42.30; that string is not a universal supported-build promise.
- Mouse/keyboard first; a physical lightgun/pedal is optional.
- Python/MCP are **not gameplay requirements**. Keep them off in a fresh project
  unless separately opting into editor automation.

## Build an input-only baseline

1. Create a blank project and wait for its map to open.
2. Copy the production `.verse` files from the source ZIP's `Content` to your
   project's `Content`. Preserve filenames. Do not copy the old descriptors,
   binary map or test fixture as an identity/migration shortcut.
3. Select **Verse → Build Verse Code**. If APIs are missing, check version/feature
   support; do not blindly remove failing code.
4. Place one **lightgun_game_manager**, one **lightgun_start_station**, and four
   **Fixed Point Cameras**. Label them `LG_Controller`, `LG_S00_START`,
   `LG_Live_Shoot`, `LG_Live_Cover`, `LG_S00_ShootTarget`, `LG_S00_CoverTarget`.
5. On all cameras set **Add to Players on Start = Off**, use matching FOV
   (55° reference baseline), and put the cover target lower than the shooting
   target. Never use one actor for two camera roles.
6. Set START `CameraProfile = ExplicitOnly` and assign its two targets.
   Keep `Encounters`/`CombatStations` empty for the first test.
7. On the manager assign the LIVE pair and START. Use `DuckIsToggle = true`,
   `ReloadOnCover = true`, `MagazineSize = 6`, `MatchTimerSeconds = 0`,
   `EnableOnboardingChecklist = true`, `LoopRoute = false`.
8. Add a player spawn pad, floor and lighting. Set one player on Team 1.
   Leave clear space at the hidden proxy: `PlayerPawnCombatTargetDistance`
   positions that target independently of the rendered view.
9. Save, launch a private session and start the game. Expect one HUD showing
   `TEST 1/3: FIRE` and no enemies. Fire once, Space to cover/refill, Space to stand.
   With no combat stations, the round stays at START.
10. Follow ADD_A_STATION.md. A separate blank map and independently recreated
    complete example are not automatically generated by this repo.

## Real hardware

Bind Fortnite **Jump** to Space or the pedal's emitted key. Configure the gun's
vendor software for pointer movement and left-click trigger. No secondary gun
button is required. Verse does not detect USB hardware or install drivers.

Perform vendor calibration first, including required tracking borders, monitor
selection and scaling. HUD marks are not a vendor tracking border. Recheck
centre/edges after resolution/scaling/FOV changes; normalization defaults are
setup-specific. Start with toggle cover; hold-to-cover needs press/release and
travel tests on your actual pedal.

Record gun, pedal, driver, display, resolution, scaling, bindings and exact
UEFN/Fortnite build. No complete hardware profile is certified here.
